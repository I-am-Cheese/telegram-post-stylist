# Telegram Post Stylist

Навык Codex для создания и редактирования постов Telegram в стиле, выработанном с владельцем ExitDLC. Отдельный навык от монтажа видео: тема или черновик → готовый текст, понятная схема оформления и картинка.

## Установка

В Codex:

> Установи навык https://github.com/I-am-Cheese/telegram-post-stylist — навык лежит в корне репозитория, имя telegram-post-stylist.

Через skill-installer используйте `--repo I-am-Cheese/telegram-post-stylist --path . --name telegram-post-stylist`. Либо клонируйте репозиторий в отдельную папку `~/.codex/skills/telegram-post-stylist` (Windows: `%USERPROFILE%\.codex\skills\telegram-post-stylist`). После установки при необходимости начните новый чат для обновления списка навыков.

## Использование

> Используй $telegram-post-stylist. Вот тема / мой черновик: …

Если сообщения ещё нет, агент попросит его прислать. По умолчанию обращение «вы». Редактура исправляет язык и оформление, сохраняя исходный смысл и заданные сведения. Она не является самостоятельной проверкой внешних фактов.

Каждый результат:

1. **TXT без разметки** — обычный текст, эмодзи и переводы строк.
2. **Схема в чате русскими тегами** — `<жирный>`, `<курсив>`, `<моно>`, `<цитата>` и ссылки точно в таком виде:

```text
<ссылка "https://link.com/test"> текст ссылки </ссылка "https://link.com/test">
```

3. **PNG-предпросмотр телефона** с тем же текстом, цитатами, выделениями и ссылками.

Никаких HTML-файлов, Markdown-файлов и дублирования готового поста перед схемой. Теги — карта ручного оформления, а не код, который Telegram автоматически исполняет. Предпросмотр синтетический, явно помечен макетом и не выдаётся за реальную публикацию. Переносы/эмодзи могут отличаться между устройствами.

## Постоянная подпись

По умолчанию в конце **всегда**:

- «Подписаться на ExitDLC» — https://t.me/ExitDLC
- «Купить приватный чит ExitDLC» — https://t.me/ExitFeedbackBot

Убирать только по прямой просьбе пользователя; агент не выбирает исключения самостоятельно. Для своего канала задайте собственный профиль. Не меняйте ссылки оригинального автора по догадке.

## Что сохраняет обучение

`SKILL.md` — рабочий порядок; `references/learned-style.md` и `decision-history.md` — действующие правила, отклонённые форматы и последние исправления. Они читаются в каждом новом чате. `examples/` содержит структурированные примеры и изображения последних выбранных результатов; это не доказательство фактов внутри постов. `assets/channel-profile.json` — точные настройки канала. Референс-скриншот автора сохранён отдельно, если доступен; никакие посторонние чаты/учётные данные Telegram не включаются.

В [history/](history/README.md) сохранён проверяемый архив тестовых TXT/PNG, рабочих генераторов и промежуточных настроек; отменённые решения явно отделены от действующих. Исходные черновики и ссылки на примеры перечислены в `references/learning-record.json`. Архив обучения этого навыка не смешивается с большим архивом монтажа.

`scripts/render_post.py` получает один JSON с русской схемой и создаёт согласованные TXT/PNG. Требуются Python 3.9+ и Pillow. Оригинальный шрифт Segoe UI читается из Windows; он не включён в репозиторий. Для других ОС предусмотрены доступные шрифты/локальные пути в профиле. Байт-в-байт повторяемость ожидается при одинаковых данных, шрифтах и среде; идентичное новое творчество и скрытое состояние модели не обещаются.

```text
python scripts/render_post.py --spec examples/giveaway.json --out post-outputs/first --scheme-out scratch/scheme.txt
python scripts/smoke_test.py
```

Обычный пост выполняется одним агентом и локальным скриптом; постоянные сабагенты и повторное скачивание истории не нужны. Отправка в Telegram/публикация не входит в нормальный вывод. Первоначальная попытка Saved Messages не удалась; навык не заявляет об отправке и не извлекает сессии/токены для обхода UI.
