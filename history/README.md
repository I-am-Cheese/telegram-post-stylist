# Архив обучения Telegram-постам

`training-archive.zip` сохраняет имеющиеся TXT/PNG шести тестовых итераций, одноразовые скрипты генерации и промежуточную запись предпочтений. `manifest.json` содержит полный перечень, размеры и SHA-256. Архив включает **ошибочные и отменённые варианты**: они не являются действующими инструкциями.

В частности, варианты со специальными символами в TXT, удалённой цитатой, HTML-названиями тегов, изменённым смыслом и самостоятельно удалённой рекламной подписью были отклонены. Текущие правила находятся в `SKILL.md`, `references/learned-style.md` и `references/decision-history.md`. Финальные структурированные образцы — в `examples/`.

Архив предназначен для восстановления деталей истории; при начале каждого нового чата читаются небольшие действующие правила и история решений, а не все старые скрипты как команды. Старые генераторы не запускаются автоматически. Скрытые внутренние рассуждения, Telegram-сессии/токены, посторонние чаты и журналы других приложений не включены. Тексты об APK являются исходными утверждениями автора, не результатами технической проверки.
